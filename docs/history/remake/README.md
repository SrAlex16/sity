## English

This directory contains the original phase-by-phase specification documents from the **Mini-Operación Remake** (September 2026), which systematically built Sity's closed cognitive loop.

These documents were the design specs written before implementation. They are preserved for historical reference and to understand the reasoning behind the current architecture.

For the current, authoritative architecture documentation, see:

- [architecture/memory.md](../../architecture/memory.md)
