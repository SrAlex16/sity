# YouTube Channel Module — Canal Spec

**Discontinued: 2026-07-08**

This document was a specification for a Spanish-language tech and AI YouTube channel presented by the Sity AI persona. The channel would cover weekly news explained for non-developers, with a pipeline from RSS ingestion → script generation → TTS → video assembly → upload → comment replies → metrics.

Every step that published or modified something required the owner's explicit confirmation.

**Why it was removed**: Video editing required human judgment that couldn't be reliably automated. Manual editing was the bottleneck. The technical pipeline worked; the human-in-the-loop requirement made it impractical.

The module is kept as a historical reference in case the concept is revisited in the future with better automation or a different scope.
